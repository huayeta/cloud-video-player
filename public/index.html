支持的格式

MP4 / MOV 原生直连
WebM 原生直连
OGG / OGV 原生直连
M3U8 (HLS) 代理流
AVI 实时转码
MKV 实时转码
FLV 实时转码
RMVB / WMV 实时转码

说明：MP4/WebM 等格式经本地服务器反向代理直连源站（透传 Range），实现秒开与任意拖拽； AVI/MKV/FLV/RMVB/WMV/MPEG 等浏览器不支持的格式，由本地 ffmpeg 实时转码为 HLS 流播放。 播放器由 embed.js SDK 以 Shadow DOM 形式嵌入，样式与页面完全隔离。 本页需通过本地服务器访问（node server.js 后打开 http://localhost:8787）。
